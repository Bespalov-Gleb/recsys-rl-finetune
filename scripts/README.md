# Скрипты запуска

- **`reproduce.sh`** — канонический порядок всех экспериментов отчёта, строго последовательно. Для воспроизведения
  нужен только он.
- **`queues/run_stage*.sh`** — очереди, через которые эксперименты шли на самом деле (тогда лежали в `scripts/`, пути внутри рассчитаны на это). Они ждали друг друга по файлам
  результатов, чтобы на GPU 8 ГБ всегда работала одна тяжёлая задача. Оставлены для прозрачности. Две оговорки:
  - `run_stage2d.sh` в ходе работы переписывался, пока один его экземпляр уже выполнялся. Из-за этого очередь
    выполнилась не в том порядке, в каком записана. Недостающие запуски доделаны в `run_stage3.sh`, а
    `grpo_played_b0.3_long` шёл параллельно с `seq5_full_real`. На результатах это не сказалось: каждый запуск
    независим и пишет свои файлы.
  - Порядок и аргументы, которые реально использовались, — в `reproduce.sh` и в начале каждого
    `results/rl_<tag>.json` (`args`).
